# docs/layouts/

**One document per file version** describing the on-disk layout: the groups, datasets and attributes, their encodings, and what each means. Each states the date its facts were verified.

**None yet.** They arrive with the adapters (V18 first, then V16 and V17) and are collected and finished with the documentation work (IP-23). Until then, what the Model holds is in [`docs/models/cdm.md`](../models/cdm.md), and a version's names and encodings are in the `layout.rs` of its adapter (`rust/io/src/adapters/`).
